## 📖 About The Project

This repository contains the source code, assets, and architectural logic for a **3BHK (3 Bedrooms, Hall, Kitchen)** interactive virtual tour. The core focus of this project is to demonstrate how modern interior design and spatial planning can seamlessly integrate with **Vaastu Shastra**, the traditional Indian system of architecture. 

Users can navigate the 3D space and click on interactive hotspots to learn *why* specific rooms, colors, and elements are placed in their respective directions.

## ✨ Key Features

- **Interactive 3D Walkthrough:** Smooth first-person navigation through the 3BHK floor plan.
- **Vaastu Hotspots:** Clickable UI cards explaining the elemental significance of each room.
- **Dynamic Compass:** An on-screen compass that tracks the user's orientation (N, S, E, W).
- **Color Therapy Integration:** Demonstrates Vaastu-approved wall colors (e.g., light yellow in the Puja room, peach in the Master Bedroom).
- **Day/Night Cycle:** Observe how sunlight enters the North-East and East windows during the morning.
